# Sheraton Bishkek — Menu (Android)

Нативное Android-приложение меню ресторана Sheraton Otel Bishkek.

## Установка

1. Скачайте [`sheratonbishkek-menu.apk`](sheratonbishkek-menu.apk).
2. На Android-устройстве разрешите установку из неизвестных источников.
3. Откройте APK и установите.

## Возможности

- Меню подгружается динамически из QR-API Menulux (актуальные категории, товары, цены, фото).
- Вложенные категории (напр. «Винная карта» → подкатегории).
- Корзина (выезжающая панель), оформление заказа.
- Языки: English / Русский / Кыргызча.
- Офлайн-режим: меню и картинки кэшируются.
- Кнопка обновления меню с подтверждением.
